# QuietHours

A calm, multiplayer virtual co-working and study platform. This repository currently contains **Milestone 1, Task 1 only**: the frontend project foundation.

## Included

- React
- Vite
- TypeScript
- Tailwind CSS
- Minimal placeholder screen to verify the foundation

## Requirements

- Node.js 20.19+ or 22.12+
- npm (included with Node.js)

## Install

```bash
npm install
```

## Start the development server

```bash
npm run dev
```

Vite will print a local URL, usually `http://localhost:5173`.

## Check the project

```bash
npm run typecheck
npm run build
```

## Scope

No authentication, PocketBase connection, rooms, chat, timers, or productivity features have been implemented. Those will be added only in later approved tasks.
